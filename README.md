# A ML-Based Approach to Swing Trading
Swing trading is a style of investing that aims to capitalize on the longer terms swings of stock, typically those that are more volatile, in an effort to increase returns relative to both the market and the simply buy-and-hold of the underlying asset. The typical timeframe for these swings can range from days to weeks, and are influenced by a variety of factors (technical, fundamental, sentiment, etc). While rule-based/mathematical models have proven effective in some contexts, this problem offers a unique opportunity to leverage machine learning based approaches. This repo covers several "levels" of models attempting to utilize both "glass box" and "black box" approaches to developing a profitable strategy.

## Model 1: Single Stock Model with XGBoost
The first "level" is testing a strategy on a single stock using basic principles from swing trading. Swing trading seeks to capitalize on the volatility of singular stocks by analyzing the momentum and "trends" of a stock across an a few days to a few weeks. A basic approach involves using technical indicators such as exponential moving averages (EMA), relative strength index (RSI), and MACD.
